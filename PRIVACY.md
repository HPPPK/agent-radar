# Agent Radar Privacy Notice

Effective date: September 17, 2026  
Version: 0.1.1

This notice describes the data handling of the Agent Radar service operated by Jingyu Pan, independent developer. The source code alone does not collect user data; the sections below apply when the hosted MCP or website is used.

## Operator and contact

- Operator: Jingyu Pan, independent developer
- Support and privacy contact: hpppk@qq.com
- Planned operator-hosted server location: Tencent Cloud, Guangzhou, China

## Service scope

Agent Radar provides read-only access to a curated digest of public Agent technology updates and public GitHub repository information. The public tools do not require an Agent Radar account and do not initiate payments, email access, private-repository access, or file access.

## Data processed

The hosted service may process:

- Tool parameters explicitly sent to Agent Radar, such as a date, search term, or result limit.
- Minimal security logs, such as timestamp, route, response status, and network information needed to detect abuse and investigate incidents.
- Administrative digest uploads authenticated by a server-side credential.

When Agent Radar is called from another platform, that platform transmits the selected tool parameters to Agent Radar and receives the tool result. Users should not include personal, confidential, credential, or regulated data in search terms.

## Data not requested by public tools

Agent Radar does not ask public users for:

- Passwords, API keys, verification codes, or payment information.
- Private GitHub repositories, email, contacts, or local files.
- Government identifiers, health information, precise location, or biometric data.
- The user's complete chat history.

Agent Radar does not sell personal data and does not use public-tool data for advertising profiles. The initial release does not use non-essential cookies or third-party advertising analytics.

## Logging and retention

The application is designed not to intentionally log MCP request bodies or search terms. If the operator opens the service on a mainland China public network, minimal security logs will be retained for the period required by applicable network-security law, currently planned as six months. Debug logs must exclude request bodies and are planned to be deleted within 30 days. Administrative publication records may be retained for integrity and incident investigation.

## Recipients and service providers

Data may be processed by:

- Tencent Cloud, as the planned infrastructure provider for the operator-hosted service.
- The platform or MCP client selected by the user, which sends tool parameters and receives Agent Radar responses.

Agent Radar does not intentionally send security logs or subscriber lists to overseas advertising or analytics services. Any future material change will require an updated notice and, where required, a consent or other lawful basis.

## Security

Agent Radar uses read-only public tools, server-side administrative credentials, request-size limits, dependency checks, and release-time secret scanning. No Internet service can be guaranteed completely secure. Security reports can be sent to hpppk@qq.com as described in SECURITY.md.

## User choices and requests

Users may request information about operator-held personal data, correction, deletion, or raise a privacy concern by emailing hpppk@qq.com. The operator will verify the request and respond within a reasonable period required by applicable law.

## Children

Agent Radar is a developer-information service and is not directed to children. Users should not submit children's personal information through search terms.

## Changes

Material changes will be published in this file and on the hosted privacy page with a new effective date.
