Agent Radar 隐私政策

生效日期：2026年9月17日 · 版本：0.1.1

源代码本身不会收集个人信息。以下内容适用于 Jingyu Pan 运营的 Agent Radar 托管网页与 MCP 服务。

运营者与联系方式

  • 运营者：Jingyu Pan（独立个人开发者）
  • 隐私与支持邮箱：hpppk@qq.com
  • 计划使用的运营服务器位置：腾讯云，中国广州

服务范围

Agent Radar 只读查询已经发布的 Agent 技术和 GitHub 项目日报。公开工具不要求 Agent Radar 账号，不访问私人 GitHub、邮箱、联系人、本地文件或金融账户。

可能处理的数据

  • 用户明确发送给 MCP 工具的日期、搜索词和返回数量。
  • 用于安全与故障调查的最小化网络日志，例如时间、接口、状态码和必要的网络信息。
  • 由服务器端凭证保护的管理员日报发布记录。

当用户通过其他平台调用 Agent Radar 时，该平台会向 Agent Radar 发送被选中的工具参数，并接收工具结果。请勿在搜索词中提交个人信息、机密信息、密码、API Key 或验证码。

不主动收集

公开工具不要求密码、API Key、支付信息、完整聊天记录、政府证件、健康信息、精确位置或生物识别数据。初始版本不使用非必要 Cookie、广告画像或第三方广告分析。

日志与保存

应用不主动记录 MCP 请求正文或搜索词。如果运营者在中国大陆公开运行服务，最小化安全日志计划按照适用的网络安全要求保存六个月；不含请求正文的调试日志计划在30天内删除。

服务提供方与数据流

计划使用腾讯云提供基础设施。用户选择的 MCP 客户端或平台负责发送工具参数并接收 Agent Radar 的结果。Agent Radar 不会主动把安全日志或订阅者名单发送给境外广告和分析服务。

用户请求

如需查询、更正、删除运营者持有的个人信息或提出隐私问题，请发送邮件至 hpppk@qq.com。运营者将在核验请求后按照适用法律要求处理。

安全与更新

公开 MCP 工具为只读；管理发布使用服务器端凭证。重大变化会更新本页的版本和生效日期。
